## 📖 About

Vortex Mod Manager is a desktop application developed by Nexus Mods for managing game mods on Windows. It handles mod installation, load order sorting, conflict detection and profile switching across a wide range of supported titles. The 2026 build brings an updated interface, faster deployment for large mod lists and improved support for newer game releases.

## 🛠 Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Mods not appearing after install | Confirm the correct game is selected and the mod extension is enabled. |
| Deployment fails on external drive | Switch deployment method in Settings to move or symlink mode. |
| Game not detected | Add the game path manually under Games, then rescan. |
| Load order keeps resetting | Disable auto sort for that game and lock the plugin order manually. |
| High memory use with large lists | Close other background apps and raise the deployment thread limit. |
| Installer stuck at extracting files | Reboot, then run the setup file again from a local drive. |
